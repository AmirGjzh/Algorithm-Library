# 📚 Algorithm Library

A growing collection of C++ algorithms and data structures I put together while practicing for competitive programming contests.

---

## ✨ Features

- Implementations collected and cleaned up over time, ready to grab whenever a contest calls for them
- Covers the usual competitive programming territory — graphs, data structures, dynamic programming, and more
- Written for clarity and quick reuse under time pressure, not textbook elegance

## ▶️ Usage

Each file is self-contained — just copy the snippet you need straight into your submission. No build step, no dependencies beyond a C++17 compiler.
